# The 15 MASH Clipper styles + Personalize

Show these as options (number, name, one line). The style board (`scripts/style_board.py`) renders all 15 on
the user's own frame so they can see each look before choosing. Each recipe says which kit skill to lead with.
Colours below are defaults; a brand kit or Personalize answers always override them.

| # | Style | How it looks | Captions | Motion + graphics | Lead skill |
|---|---|---|---|---|---|

## Personalize questions (ask together, one message)
1. Colours: brand hex codes, a logo/brand-kit file, or "pick from my footage".
2. Fonts: names, or "pick for me".
3. Captions: none / clean line / boxed / bold words / serif + bold.
4. Amount of graphics: minimal / medium / heavy.
5. A reference reel or video (link or file) if they have one; copy its pacing and layout, never its brand.

## Rules for every style
- Every style follows `editing-rules.md` (verbatim captions, transitions, safe zone, original audio).
- Pick visuals that match the exact words at that moment; prefer real UI (phone feeds, chats, dashboards)
  over generic stock.
- Change something every 1.5-3 s (a card, a key word, a move), but never at the cost of smoothness.
