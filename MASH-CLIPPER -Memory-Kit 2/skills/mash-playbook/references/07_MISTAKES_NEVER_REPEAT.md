# 07 · Mistakes we made once; never again (every item was a user correction)

| # | What went wrong | The permanent rule |
|---|---|---|
| 1 | Random 45 s windows as clips | Clips are story-shaped: hook → body → payoff → ending |
| 2 | Interview clip where only the host asked (no answer) | Always question + answer; both people visible |
| 3 | Vertical crop centred on the wrong person after a camera switch | Split at camera cuts, frame the speaker per shot, verify with a contact sheet |
| 4 | Cut ended mid-sentence | End on the complete sentence; re-transcribe every clip |
| 5 | Stray syllable / stammer / repeated word kept | Cut them; check each join in the re-transcription |
| 6 | Long gap left in the clip | Trim pauses > 0.35 s to a breath |
| 7 | Captions were my headlines, not her words | Exact spoken words, in order, timed to each word |
| 8 | Captions came before she spoke | Start on the first spoken word |
| 9 | Too much text at the start | Open straight on the spoken line, no title/kicker/headline |
| 10 | Text repeated what a graphic already said | No captions while a graphic shows the same words |
| 11 | Text overlapped / two scenes visible together | Gated scenes, sequential dip transitions, one caption at a time |
| 12 | Highlights appeared before the line | Highlight after the line has fully appeared, on the key word |
| 13 | Phone screen flashed white | No 3D tilt on image layers; decode images before first frame |
| 14 | Text "juggling", glitchy motion | No blur on running text, transforms+opacity only, one zoom system |
| 15 | Transitions slid or double-exposed | Fade-out then fade-in, never overlap |
| 16 | One-sided look (same card for 60 s) | Mix scene types + B-roll; use full-frame shots too |
| 17 | Tape-print frame used for the whole middle | Alternate print with full-frame zoomed shots + captions on chest |
| 18 | Layout empty on top / stack of tags at bottom | Centre the layout; move the main element when the stack grows |
| 19 | Speaker boxed with a tight face crop | Use the original horizontal footage in a 16:9 box |
| 20 | Graphics too small | Bigger cards/phones (phone may bleed off the bottom); keep key content in the safe zone |
| 21 | SFX and music added unasked | None by default; original audio only |
| 22 | Voice processed (EQ/normalise) | Never touch original audio; master copies the stream |
| 23 | Phone preview had no sound | Phone-safe AAC 44.1k + loudness-normalised copy; tell them to unmute |
| 24 | 4K final not Premiere-friendly | Closed GOP, keyframe every 30 frames |
| 25 | Rendered 1080p/draft when 4K asked | Render only the deliverable; previews at `-q looks` |
| 26 | Asked before routine steps | Just do routine steps; ask only about money, deletions, publishing, real creative choices |
| 27 | Did not say where the final is | Always give the exact path, `open -R`, ETA |
| 28 | Spent credits on generation | Unlimited mode only; ask + estimate first for anything paid |
| 29 | Brand words in image prompts baked logos | Describe the style, add "no text, no logos, no brand marks" |
| 30 | Edited before the full feedback batch | Wait for "go" when they are sending notes |
| 31 | Said "ready" without looking | Snapshot every beat and every transition midpoint, 2-3 passes |
| 32 | Layout glitches (e.g. caption on a child's face) | Check face clearance at 3 points per beat; lift text on B-roll |
| 33 | Cover with one person when the clip is a conversation | Interview cover = both people side by side, facing each other, equal size |
| 34 | Time-map drift after trimming | Rebuild the time map from source segments |
| 35 | Long files could not be sent to the phone | ≤30 MB chat limit: send phone copy, give the path of the master |
